# Контракт в TypeSpec, сгенерированный код лежит в репозитории

Источник правды об API это `api/main.tsp`. Из него одной командой `mise run generate` получаются OpenAPI-спецификация (`api/generated`), клиентский SDK для фронтенда (`web/src/api/generated`) и типы обработчиков Fastify (`server/generated`). Сервер не описывает маршруты руками: `fastify-openapi-glue` строит их из OpenAPI, проверяет запросы и сериализует ответы по схемам контракта, а обработчики типизированы сгенерированным `RouteHandlers`.

Сгенерированные файлы закоммичены, чтобы контракт и SDK были видны в ревью, а Docker-образ собирался без генераторов. Расхождение ловит `mise run generate:check`: CI повторяет генерацию и падает, если в этих каталогах появились изменения или новые файлы.

## Consequences

- Сгенерированные каталоги нельзя править руками: изменение API начинается с `api/main.tsp`.
- В проекте используется TypeScript 6, а не 7: генератор SDK работает через классический API компилятора, которого в TypeScript 7 нет.
