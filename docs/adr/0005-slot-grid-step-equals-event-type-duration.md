# Шаг слотов равен длительности типа встречи

Слоты каждого типа встречи идут подряд от начала рабочего дня: первый начинается в 09:00, следующий в момент окончания предыдущего, последний заканчивается не позже 18:00. Шаг стартов равен длительности типа, а не общей сетке в 15 минут: гость видит короткий список непересекающихся интервалов, а день владельца не дробится встречами со сдвигом.

Сервер принимает запись только на время, которое совпадает с началом слота из окна записи этого типа. Занятость при этом считается по интервалам, а не по сетке: записи двух типов конфликтуют, если их интервалы `[начало, конец)` пересекаются хотя бы частично, а встреча, которая начинается в момент окончания другой, конфликтом не считается.

## Considered Options

- Общий шаг 15 минут для всех типов: больше вариантов начала для длинных встреч, но длинный список пересекающихся слотов и фрагментация дня.
