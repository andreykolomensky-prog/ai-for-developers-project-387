# Главная страница проверяется компонентными тестами

Главная страница не обращается к API, поэтому её поведение (текст о сервисе и переход на страницу записи) проверяется в jsdom через Testing Library: тест рендерит приложение целиком с маршрутизацией и кликает по ссылкам, как гость. Браузерные сценарии с настоящим сервером оставлены для бронирования, где важна связка интерфейса, API и правил занятости.
