# Сервер запускается без сборки TypeScript

Node.js 26 исполняет TypeScript напрямую, срезая типы, поэтому у сервера нет шага компиляции: `node server/main.ts` работает одинаково в разработке, в тестах и в контейнере. Цена решения: импорты пишутся с расширением `.ts`, а конструкции с поведением во время выполнения (`enum`, `namespace`, свойства-параметры конструктора) запрещены настройкой `erasableSyntaxOnly`.

## Considered Options

- Компиляция `tsc` в `dist/`: привычно, но добавляет шаг сборки и расхождение между тем, что тестируется, и тем, что запускается.
