# Один процесс отдаёт API и фронтенд

Приложение публикуется одним Docker-образом и слушает один порт из `PORT`, поэтому сервер Fastify сам раздаёт собранный фронтенд из `dist/web`, а API живёт под префиксом `/api`. Отдельный хостинг статики и CORS не нужны, зато любые пути вне `/api` принадлежат интерфейсу: на неизвестный адрес сервер отвечает `index.html`, и маршрутизацию выполняет клиент.

## Considered Options

- Отдельные сервисы для фронтенда и API: два деплоя, CORS и две публичные ссылки ради приложения, которое проверяется одной командой `docker run`.
