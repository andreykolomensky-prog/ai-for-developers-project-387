# Расписание владельца задано в коде по московскому времени

Владелец один, поэтому его расписание это константа сервера: рабочие часы с 09:00 до 18:00 каждый день недели в часовом поясе `Europe/Moscow`, окно записи 14 календарных дней, начиная с сегодняшнего дня по Москве. API отдаёт моменты времени в UTC, а даты окна записи и название часового пояса в поясе владельца, и интерфейс показывает время гостю тоже по Москве. Пересчёт в пояс гостя и настройка расписания через интерфейс сознательно не делаются: задание ограничивает проект одним владельцем без личных кабинетов.

## Consequences

- Слот сегодняшнего дня, который уже начался, считается недоступным, поэтому к вечеру сегодняшний день остаётся в окне записи без свободных слотов.
- Гость из другого часового пояса видит московское время с подписью, а не своё местное.
