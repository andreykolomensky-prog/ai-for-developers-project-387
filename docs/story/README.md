# Картинки для README

Инфографика из корневого `README.md`. Каждая картинка это снимок одной «плиты» страницы [src/story.html](src/story.html) в светлой и тёмной теме.

| Что лежит                             | Зачем                                                                            |
| ------------------------------------- | -------------------------------------------------------------------------------- |
| `NN-имя.light.png`, `NN-имя.dark.png` | Плиты для светлой и тёмной темы GitHub. README выбирает нужную через `<picture>` |
| `demo.gif`                            | Одиннадцать кадров настоящего приложения с подписями                             |
| `src/story.html`                      | Исходник всех плит: разметка, стили и данные диаграмм в одном файле              |
| `src/shots/`                          | Скриншоты приложения, которые показывает плита «Демо»                            |
| `src/capture.mjs`                     | Скрипт съёмки плит                                                               |

## Как поменять картинку

1. Поправьте разметку нужной плиты в `src/story.html`. Плита это элемент `<section class="plate" data-name="NN-имя">`, имя задаёт имя файла.
2. Откройте `src/story.html` в браузере и проверьте обе темы. Тема переключается атрибутом `data-theme` у корневого элемента или настройкой системы.
3. Пересоберите картинки из корня репозитория:

   ```bash
   node docs/story/src/capture.mjs
   ```

Скрипт использует Playwright из зависимостей проекта и шрифты Google Fonts, поэтому ему нужен доступ в сеть. Закоммиченные картинки дополнительно сжаты до палитры в 256 цветов. Скрипт делает то же самое, если рядом установлен пакет `sharp`, например командой `npm install --no-save sharp`. Без него картинки выходят в два-три раза тяжелее.

## Что важно помнить

- Числа на плитах сняты из истории Git и GitHub Actions на 23:44 МСК 27 ноября 2026 года. Это отчёт о конкретном вечере, а не живая панель: при обычных правках кода плиты не обновляются.
- Актуальные команды, правила и настройки описаны текстом в разделе «Справочник» корневого `README.md`. При изменении поведения сначала правится он.
- Скриншоты в `src/shots/` сняты с запущенного приложения. Их источник: сценарий, совпадающий с браузерным тестом `e2e/booking.spec.ts`.
